# The Passport Page of a Country That Isn't There

Invented passport spread for the **Republic of Krzvania** — a desert
caravan-route republic. Holder: Amina Rashid, licensed caravan guide
(licence C-0917).

Run `python3 main.py` — it writes a 1024x1024 PNG to `/output/entry.png`
(no network; the portrait is read from `portrait.jpg` beside `main.py`).
