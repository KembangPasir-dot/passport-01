Invented passport spread for the **Republic of Krzvania** — a desert caravan-route republic. Holder: Amina Rashid, licensed caravan guide (licence C-0917). A two-page spread: data page with portrait, MRZ and observations, and a visas page with paired arrival/departure stamps, a Desert Crossing Endorsement and a Mirazh visitor visa.

## Run it

```sh
python3 main.py
```

It writes a 1024x1024 PNG to `/output/entry.png` (no network; the portrait is read from `portrait.jpg` beside `main.py`).
